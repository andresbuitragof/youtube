# Thumbnail brief
Entregar 3 conceptos: emoción/sujeto, texto (<=3 palabras), contraste, composición, color de marca. Incluir prompt para generador de imágenes y checklist: legible en móvil, una idea, coherente con el título. Proponer test A/B (YouTube Test & Compare) con hipótesis y métrica (CTR/tiempo de visualización).
