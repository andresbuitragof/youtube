# Script retention
Estructura: gancho (0-15 s, promesa + prueba), contexto mínimo, bucles abiertos cada 60-90 s, reinicios de atención (cambio visual/ritmo), payoff, CTA suave (suscripción/afiliado) sin cortar el flujo.
Entregar guion con marcas de tiempo estimadas, notas de B-roll y 2 variantes de gancho para probar.
