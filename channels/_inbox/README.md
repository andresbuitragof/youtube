# Bandeja de entrada
- `audio/E01.m4a … E11.m4a`: audios originales (~6 min en total) pendientes de edición.
- `transcripts/`: salida de `python scripts/transcribe.py channels/_inbox/audio`.

Flujo: transcribir → `/script-retention` (estructura y ganchos) → `/video-seo` → `/thumbnail-brief` → `/shorts-repurpose` → `/content-calendar`.
Cuando se asigne un canal, mover a `channels/<slug>/`.
